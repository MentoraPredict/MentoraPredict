# Web Technologies

| Technology | Purpose in MentoraPredict Web |
| --- | --- |
| React 19 | Component-based user interface and role dashboards |
| TypeScript | Static typing for components, services, and API contracts |
| Vite 8 | Development server and production/desktop builds |
| React Router 7 | Public, protected, nested, and role-based navigation |
| Tailwind CSS 4 | Utility styling backed by shared design tokens |
| TanStack Query 5 | Remote data fetching, caching, invalidation, and persistence |
| Zustand 5 | Lightweight client state, especially authentication/session state |
| Axios | Shared HTTP client, authorization headers, and token refresh |
| Socket.IO Client | Real-time notification delivery |
| React Hook Form | Form state and validation workflows |
| Recharts | Course performance and analytics charts |
| Framer Motion | Route and interface transitions |
| React Icons | Consistent icon library |
| Storybook 10 | Isolated component documentation and visual development |
| Vitest + Playwright | Unit and browser-based component testing |

Inter is bundled through Fontsource to avoid a runtime dependency on an external font CDN.
